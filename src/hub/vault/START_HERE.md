# AI Memory Vault

## Start every substantive task

1. Read `MEMORY.md`.
2. Read `INDEX.md`.
3. Read only the files that are relevant to the task.
4. Follow `PROTOCOL.md` when you record anything.

## What goes where

- `MEMORY.md`: durable facts and preferences that matter in every task.
- `profile/`: what is known about the user, split into confirmed and to confirm.
- `areas/`: ongoing areas of life or work that are not projects.
- `projects/`: one folder per project, with an overview, the current state and a decision log.
- `sessions/`: one file per day with short summaries of what was done.
- `inbox/`: new, unconfirmed notes waiting for review.
- `archive/`: anything replaced or no longer true. Nothing is deleted.

## Never store

Passwords, API keys, recovery codes, authentication cookies, private keys, or full financial account numbers.
